# Deploy Strudel Canvas to GitHub Pages

1. Create a public repository named `strudel-canvas` under GitHub account `zehsilva`.
2. Upload all repository files, preserving `index.html` at the root.
3. Go to repository **Settings → Pages**. Select **Deploy from a branch**, then **main**, folder **/(root)**, and Save.
4. Confirm https://zehsilva.github.io/strudel-canvas/ after Pages finishes deployment.

Future pushes to `main` will redeploy the site. The site itself is fully static; the external Strudel Web library and sample bank still require a working internet connection.
